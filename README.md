# A fixed Pauli-norm threshold for diagonal matrix powering

Daniel Fredriksen · Quantyra Inc. · [ORCID](https://orcid.org/0009-0002-9123-7435)

For any fixed Pauli coefficient norm cap above one, the threshold version of estimating a single diagonal entry of a polynomial matrix power is PromiseBQP-complete at inverse-polynomial precision. At cap one, an efficient classical sampling algorithm is known.
